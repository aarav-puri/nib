Nib is a browser extension for AP Classroom. It hides the correct and incorrect markers so you can retry finished assignments and test yourself honestly.

Download the extension How to install
Load unpacked in Chrome, Edge, or Brave. Not on any store yet.

Hide the markers

Covers the green and red correctness highlights and the answer explanations, so a completed assignment reads like a fresh one.

One switch

Turn hiding on or off from the Nib popup or the small floating panel on the page. Reveal the answers when you are ready to check.

Nothing leaves your browser

No account, no API key, no network requests. Nib only runs on AP Classroom and only changes how the page looks.
